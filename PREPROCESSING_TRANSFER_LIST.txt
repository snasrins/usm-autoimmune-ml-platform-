=============================================================================
WHAT'S NEW - FEATURE SUMMARY
=============================================================================

✅ IMPUTATION (Research Study: Median for continuous, Mode for categorical)
   - Configurable strategies: 'median', 'mean', 'most_frequent', 'constant'
   - Separate handling for numeric vs categorical columns
   - Tracks number of values imputed
   - Preserves target column (no imputation)
   - Default: ENABLED

✅ WINSORIZATION (Research Study: 1st and 99th percentiles)
   - Configurable percentile limits
   - Caps extreme outliers to reduce impact
   - Tracks values capped per column
   - Excludes target column
   - Default: ENABLED

✅ COMPOSITE PATHOLOGICAL FEATURES (Research Study Approach)
   - Pancytopenia: ALL blood counts low (WBC, HGB, PLT < 10th percentile)
   - Cytopenia: ANY blood count low (WBC, HGB, or PLT < 10th percentile)
   - Liver Damage: ANY liver enzyme high (ALT or AST > 70th percentile)
   - High Inflammation: CRP/ESR ratio > 75th percentile
   - Low Complement: C3/C4 ratio < 25th percentile
   - Configurable percentile thresholds
   - Auto-detects column names
   - Default: ENABLED

✅ SLEDAI BINARY TARGET (Research Study: SLEDAI-2000 > 4)
   - Creates binary classification target from SLEDAI score
   - Configurable threshold (default: 4.0)
   - Replaces target column when enabled
   - Tracks class distribution
   - Default: DISABLED (use disease_severity by default)

✅ PERCENTILE-BASED CUTOFFS
   - Cohort-based thresholds for blood counts, liver enzymes
   - Used in composite feature creation
   - Transparent and reproducible
   - Configurable percentiles
